What's Happening

Working on a few projects at the moment.

  • ki-v3 - The third take on my magnum opus Ki, a programming language from scratch that aims to be a modern non-production alternative to C.
  • fob - Compiler backend API for generating IR and assembly from scratch. It was written to centralize and speed up my compiler projects.
  • fof - Barebones C compiler written for testing and demonstrating the usage of the fob compiler backend api.
  • bp - No-nonsense build tool written to avoid the frustration of dealing with overly complex build systems like Make and CMake.
